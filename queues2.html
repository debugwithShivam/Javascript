The Wasted Space Problem

In a simple queue, after dequeue operations, the spaces at the front of the array cannot be reused for new elements. This leads to false overflow — the queue reports full even though empty spaces exist at the beginning!

Wasted Space (cannot be reused)

Circular Queue (Ring Buffer)

Uses modulo arithmetic (% capacity) to wrap around and reuse empty spaces. Solves the wasted space problem.

Solution: (rear + 1) % capacity

How Circular Queue Works

  • ● When rear reaches the end, it wraps to index 0 using modulo
  • ● Full condition: (rear + 1) % cap == front
  • ● Empty condition: front == -1
  • ● One slot is always left empty to distinguish full from empty
