Array-Based Queue

Implements a queue using a fixed-size or dynamic array with front and rear pointers.

Enqueue

Dequeue
O(1)
Space
O(n) fixed
Limitation
Fixed capacity*

Circular Buffer: Uses modulo arithmetic to reuse empty spaces at the front, preventing "false overflow".

Linked List Queue

Implements a queue using nodes with data and next pointers, maintaining head and tail references.

Enqueue
O(1)
Dequeue
O(1)
Space
O(n) dynamic
Advantage
No capacity limit

Dynamic Growth: Memory allocated per element. No wasted space, but extra memory overhead per node for the pointer.

Detailed Comparison

Aspect Array Queue Linked List Queue
Memory Allocation Contiguous (fixed block) Scattered (node per element)
Memory Overhead Low (just data + 2 pointers) High (extra pointer per node)
Cache Performance Excellent (spatial locality) Poor (pointer chasing)
Overflow Condition When rear == capacity - 1 (linear) or full (circular) Only when heap memory exhausted
Implementation Complexity Moderate (circular logic) Simple (straightforward)
Use Case Bounded buffers, high-performance systems Unbounded queues, when size unknown

Implementation Reference (Python)

class CircularArrayQueue:
    def __init__(self, capacity):
        self.capacity = capacity
        self.queue = [None] * capacity
        self.front = self.rear = -1
    
    def enqueue(self, data):
        # Check if queue is full
        if (self.rear + 1) % self.capacity == self.front:
            raise Exception("Queue Overflow")
        
        # First element
        if self.front == -1:
            self.front = 0
        
        self.rear = (self.rear + 1) % self.capacity
        self.queue[self.rear] = data
    
    def dequeue(self):
        if self.front == -1:
            raise Exception("Queue Underflow")
        
        data = self.queue[self.front]
        
        # Last element removed
        if self.front == self.rear:
            self.front = self.rear = -1
        else:
            self.front = (self.front + 1) % self.capacity
        
        return data
